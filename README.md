How to use the config.csv:

Line 0 is the Host's team
Line 1 is the Client's team

Put the name of a valid unit type to add the unit to the team, and separate every unit with a ,
There should be **NO WHITESPACE** unless it is part of the units name (e.g. "glass cannon")
There should not be a trailing , at the end of the line
